# Branding oficial de Axhum Tech

Esta carpeta contiene las fuentes visuales aprobadas a partir del logo maestro circular de Axhum Tech.

## Estructura

- `logos/`: logos e isotipos SVG oficiales.
- `source/`: logo maestro raster recibido y aprobado por el fundador.
- `social/`: piezas maestras para compartir la web.
- `previews/`: renders PNG para revision visual; no son archivos maestros.

## Reglas

- Usar nombres `on-light` y `on-dark` segun el fondo real.
- No editar un SVG oficial sin respaldar la version anterior en `_legacy/`.
- La X oficial tiene dos brazos azul marino a la izquierda y un chevron naranja a la derecha, dentro de un aro circular multicolor.
- No sustituirla por una X cruzada, una letra X tipografica ni el isotipo Operations X anterior.
- Las derivaciones raster se generan desde los SVG.
- Los placeholders anteriores viven en `_legacy/branding-v1-placeholder-20260802/`.
