# Fotografias institucionales

## Retrato del fundador

No hay un retrato publicado actualmente. Las paginas usan una composicion institucional temporal hasta contar con la fotografia definitiva.

Requisitos recomendados:

- Formato vertical, proporcion aproximada 4:5.
- Resolucion minima de 1600 x 2000 px.
- Luz natural o iluminacion suave.
- Fondo simple, claro o neutro.
- Encuadre desde el pecho o cintura.
- Ropa lisa, sin logos visibles.
- Expresion natural y profesional.

Cuando se apruebe la fotografia, la version optimizada para web debe guardarse en esta carpeta. Los ensayos rechazados se conservan fuera de los assets activos, dentro de `_legacy`.
