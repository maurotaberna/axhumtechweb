## Diagnostico ejecutivo

La direccion de marca esta definida, pero el sistema final de identidad no esta cerrado. Existe una decision conceptual a favor de Operations X y la paleta azul noche, petroleo, cobre, marfil y texto oscuro. Sin embargo, los recursos disponibles muestran variantes incompatibles entre si.

No conviene incorporar mas material visual a la web hasta resolver el isotipo definitivo y producir capturas comerciales actuales.

## Inconsistencias encontradas

### 1. Isotipo

- El branding master propone una X geometrica grande.
- Los SVG de la web usan una X superpuesta dentro de un cuadrado redondeado.
- Axhum Gestion implementa un simbolo que visualmente se lee como una A.
- Las capturas comerciales antiguas tambien muestran una A y una paleta turquesa.

Decision resuelta: Operations X es la forma oficial y la A no se usa en nuevas piezas web.

### 2. Logotipo

Los SVG actuales son funcionales como placeholders, pero no constituyen un paquete de identidad final:

- Usan `Georgia` y `Arial` como fuentes declaradas, sin letras convertidas a curvas.
- No hay construccion geometrica ni area de seguridad documentada.
- No hay variantes vertical, horizontal reducida y solo wordmark formalizadas.
- No hay version preparada para tamanos muy pequenos.
- No hay archivos maestros de diseno en SVG/PDF con trazados finales.

### 3. Tipografia

- El branding master propone DM Serif Display, Inter e IBM Plex Mono.
- La web actual usa Manrope y DM Sans.
- Axhum Gestion usa DM Serif Display, Inter e IBM Plex Mono.
- Comanda mantiene otro lenguaje visual.

Decision necesaria: confirmar si la identidad corporativa conserva la serif editorial o adopta una familia sans moderna. La interfaz de producto puede usar un sistema distinto, pero debe estar documentado.

### 4. Capturas de producto

- Las capturas del ERP en `publicidad y ventas` pertenecen a una version visual anterior y muestran `Axhum Tech Local` o `Axhum Tech ERP Desktop`.
- Varias capturas estan en modo oscuro, contrario a la direccion clara elegida para la web.
- Las capturas actuales de Axhum Gestion muestran el producto correcto, pero necesitan una sesion comercial limpia y encuadres consistentes.
- Las capturas de Comanda muestran textos de desarrollo como version `v0.1.0`, `Runtime activo` y `Fase 6`.
- Los datos son demostrativos y no deben presentarse como resultados de clientes.

### 5. Mensaje comercial

El material existente incluye afirmaciones valiosas que no aparecen todavia en la web:

- Operacion local y sin depender de internet.
- Escenario ideal de una PC con Windows.
- Prueba de 7 dias.
- Licencia de pago unico.
- Demo con datos reales del comercio.
- Instalacion, capacitacion y soporte como servicios adicionales.

Estas condiciones deben confirmarse antes de publicarlas. Tambien debe explicarse con claridad que el sistema no emite factura fiscal ni se integra con ARCA/AFIP.
